We add a masked-diffusion backend calling `LLaDA/generate.py`.\n\t2. **`max_tokens`**** has no LLaDA equivalent.** The authors' `DEFAULT_MAX_TOKENS_GENERATION = 10_000` is an autoregressive *ceiling with early exit*. LLaDA has no early exit — it must commit every one of `gen_length` masked positions. `gen_length` is therefore a decoding *parameter*, not a translation of a ceiling. This is the object of the present calibration.\n\t3. **`top_p`**** cannot be matched.** All ten author eval configs set `top_p: 0.8`; LLaDA's sampler exposes no `top_p`. Recorded explicitly as `top_p_non_equivalence` rather than left implicit.\n\tThe judge transport uses a direct `AsyncOpenAI` client rather than `judge_api.judge_one`, which hard-requires the uninstalled and unstubbable `llmcomp`. Design\n**Instrument is claim-independent.** The 100 questions are fixed regardless of which false fact was trained (`coherence.py`: *\"This eval is claim-independent\"*). **No belief rate is computed anywhere in this pipeline.** The claim enters only to select the salience rubric, a judge-side input.\n**Two roles, and the distinction is load-bearing.**\n- **SELECTION** — base model, no adapter. Belief rate is undefined for it, so the budget cannot be tuned on the outcome even in principle. This alone decides the budget.\n- **DIAGNOSTIC** — the six study adapters. Run because \"detect model collapse\" is exactly what we need to know, but **excluded from the decision**, so the budget is not selected on a property of the objects under test.\n**Grid: published values only.** `gen_length ∈ {64, 256, 512}` (LLaDA Appendix B.4 - 1024 is the *Base* model's setting, Instruct is tuned from these); `steps = gen_length` (README FAQ #3); `block_length ∈ {gen_length, 32, 8}` (B.4 / [EVAL.md](http://EVAL.md) Instruct values); `confidence_eos_eot_inf` per the [EVAL.md](http://EVAL.md) Instruct column. Fixed: `temperature=0.7`, `cfg_scale=0.0` (B.3, fair comparison against ARMs), `remasking=low_confidence` (B.4). No cell is this project's invention; `block_length=128`, our own legacy setting, is *not* a published Instruct value and was excluded.\n---\n## 3.
